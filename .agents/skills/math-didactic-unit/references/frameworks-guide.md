# Theoretical Frameworks Reference Guide

This folder contains pointers and references to the declarative framework manifests:

1. **Theory of Didactical Situations (TDS - Guy Brousseau)**:
   - File: `frameworks/brousseau-tsd.yaml`
   - Phases: Action, Formulation, Validation, and Institutionalization situations.
   - Vigilance: Topaze Effect, Jourdain Effect, Metacognitive Shift.

2. **Onto-Semiotic Approach (OSA / EOS - Juan D. Godino)**:
   - File: `frameworks/godino-eos.yaml`
   - Dimensions: Onto-semiotic configurations (Problems, Language, Concepts, Propositions, Procedures, Arguments) and Didactic Suitability criteria.

3. **APOS Theory (Ed Dubinsky & RUMEC)**:
   - File: `frameworks/dubinsky-apoe.yaml`
   - Cycle: Activities, Class Discussion, Exercises (ACE).
   - Structures: Action -> Process -> Object -> Schema.

4. **Registers of Semiotic Representations (TRRS - Raymond Duval)**:
   - File: `frameworks/duval-trrs.yaml`
   - Registers: Graphical, Tabular, Verbal, Algebraic.
   - Operations: Treatment (within-register) and active Conversion (between registers).

5. **JSON Schema Contract**:
   - `schemas/didactic-unit.json`
