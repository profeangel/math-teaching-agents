# Dynamic Mathematical Visualization Guide

1. **Supported Tooling**:
   - Manim Community Edition (Python) for cinematic vector animations.
   - GeoGebra / Desmos for interactive exploratory geometric constructions.

2. **Didactic Principles**:
   - Integration with `manim-motion-engineer` and `geogebra-desmos-engineer` subagents.
   - Focus on visual and geometric intuition supporting analytical rigor.
